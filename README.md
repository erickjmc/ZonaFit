# ZonaFit - Sistema de Gestion de Gimnasio

Sistema de gestion de clientes y membresias desarrollado 
 
## Tecnologías
- Java
- Maven
- Mysql
- JDBC
- Intellij IDE

## Estructura 
- `Conexion.java` - Conexion a base de datos
- `Cliente.java` - Modelo de cliente
- `ClienteDAO.java` - Acceso a datos
- `Main.java` - Lógica principal del sistema

## Instalacion
1. Clonar el repositorio:
   ```bash
   git clone https://github.com/erickjmc/ZonaFit.git
   ```

2. Configurar la base de datos en `Conexion.java`
3. Ejecutar con Maven
